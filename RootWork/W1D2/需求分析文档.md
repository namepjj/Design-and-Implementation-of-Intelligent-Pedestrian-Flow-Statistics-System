## 1. 引言

### 1.1 编写目的

本文档旨在明确"基于 YOLO 和多目标跟踪的人流量智能统计系统"的功能需求、性能需求、接口需求及非功能性需求，为后续系统设计、编码实现、测试验证和项目验收提供依据。文档面向项目开发人员、测试人员、指导教师及评审专家。

### 1.2 项目背景

随着智慧城市、公共安全与商业运营的发展，对特定区域内人员数量、进出流量、停留时长等信息的实时准确统计需求日益增长。传统人工计数方式效率低、误差大、成本高；红外对射、压力传感等方案部署受限且无法提供轨迹信息。基于深度学习的目标检测（YOLO 系列）与多目标跟踪（MOT，如 ByteTrack、DeepSORT、BoT-SORT）技术已日趋成熟，能够在普通监控摄像头视频流中实现高精度、实时的人员检测与身份保持，为人流量智能统计提供了可行的技术路径。

### 1.3 术语与缩略语

| 术语/缩写 | 全称 | 说明 |
| :--- | :--- | :--- |

| mAP | mean Average Precision | 平均精度均值，检测精度评价指标 |
| MOTA | Multiple Object Tracking Accuracy | 多目标跟踪精度指标 |
| IDF1 | ID F1 Score | 身份保持能力评价指标 |
| ROI | Region of Interest | 感兴趣区域（计数线/多边形区域） |
| ReID | Re-Identification | 行人重识别 |
| GPU | Graphics Processing Unit | 图形处理器 |

## 2. 项目概述

### 2.1 项目目标

| 序号 | 目标类别 | 具体描述 |
| :---: | :--- | :--- |
| G1 | 检测精度 | 使用 YOLO11n/YOLO11s 模型对视频中行人进行检测，mAP@0.5 ≥ 0.85 |
| G2 | 跟踪稳定性 | 采用 ByteTrack/BoT-SORT 保持目标 ID，IDF1 ≥ 0.75 |
| G3 | 计数准确率 | 支持计数线、多边形区域两种模式，双向计数准确率 ≥ 95% |
| G4 | 实时性 | 1080P 视频在 GPU 环境下处理帧率 ≥ 25 FPS，CPU 环境 ≥ 5 FPS |
| G5 | 可视化 | 提供实时预览窗口，叠加检测框、跟踪 ID、轨迹线、计数信息 |
| G6 | 结果输出 | 支持视频文件保存、CSV/JSON 报表导出、控制台日志输出 |
| G7 | 易用性 | 命令行一键运行，配置文件驱动，支持批量视频处理 |

### 2.2 系统总体架构

| 层级 | 模块 | 主要职责 |
| :--- | :--- | :--- |
| 输入层 | 视频采集模块 | 读取本地视频文件 / 摄像头 / RTSP 流 |
| 预处理层 | 图像预处理模块 | 帧读取、缩放、色彩空间转换、ROI 裁剪 |
| 核心算法层 | 目标检测模块 | 基于 YOLO11 完成行人检测 |
| 核心算法层 | 多目标跟踪模块 | 基于 ByteTrack/BoT-SORT 完成 ID 关联 |
| 核心算法层 | 人流量统计模块 | 计数线穿越判定、区域内人数统计 |
| 输出层 | 可视化模块 | OpenCV 绘制、GUI 显示 |
| 输出层 | 数据存储模块 | 视频录制、CSV/JSON 报表、日志 |
| 支撑层 | 配置管理模块 | YAML 配置加载、参数校验 |
| 支撑层 | 设备管理模块 | GPU/CPU 自动切换 |

## 4. 数据需求

### 4.1 输入数据

| 数据项 | 类型 | 说明 | 示例 |
| :--- | :--- | :--- | :--- |
| 视频文件 | MP4/AVI/MOV | 待分析的监控视频 | `videos/2015_05_11_20_26_29FrontColor.avi` |
| 摄像头索引 | int | USB 摄像头编号 | 0 |
| 流地址 | string | RTSP/HTTP 流 URL | `rtsp://192.168.1.10:554/stream` |
| 模型权重 | .pt | YOLO 预训练权重 | `models/yolo11n.pt` |
| 配置文件 | .yaml | 运行参数配置 | `config.yaml` |

### 4.2 中间数据

| 数据项 | 数据结构 | 说明 |
| :--- | :--- | :--- |
| 帧图像 | `np.ndarray (H,W,3)` | BGR 格式的原始帧 |
| 检测结果 | `List[Dict]` | 每项含 bbox、conf、cls |
| 跟踪结果 | `List[Dict]` | 每项含 track_id、bbox、conf |
| 轨迹缓存 | `Dict[int, deque]` | 每个 ID 的历史中心点队列 |
| 计数状态 | `Dict[str, int]` | `{"in": n1, "out": n2}` |
| 已计数集合 | `Dict[str, Set[int]]` | `{"in": set(), "out": set()}` |

### 4.3 输出数据

| 数据项 | 格式 | 内容 |
| :--- | :--- | :--- |
| 标注视频 | MP4 (H.264) | 带检测框、ID、计数信息的视频 |
| 明细报表 | CSV | 帧号、时间戳、track_id、bbox、事件类型 |
| 汇总报表 | JSON | 视频名、总进入、总离开、峰值、处理耗时 |
| 运行日志 | TXT/LOG | 时间戳、级别、模块、消息 |

## 5. 性能需求

### 5.1 处理性能指标

| 指标 | CPU 环境 | GPU 环境（RTX 3060） | 备注 |
| :--- | :--- | :--- | :--- |
| 单帧处理时间 | ≤ 200 ms | ≤ 40 ms | 640×640 输入 |
| 处理帧率 FPS | ≥ 5 | ≥ 25 | 1080P 视频 |
| 端到端延迟 | ≤ 500 ms | ≤ 150 ms | 摄像头实时场景 |
| 启动时间 | ≤ 5 s | ≤ 3 s | 冷启动加载模型 |
| 内存占用 | ≤ 2 GB | ≤ 4 GB（含显存） | 峰值 |

### 5.2 精度指标

| 指标 | 目标值 | 测量方法 |
| :--- | :--- | :--- |
| mAP@0.5 | ≥ 0.85 | 使用 MOT17/自建数据集评估 |
| mAP@0.5:0.95 | ≥ 0.55 | 同上 |
| MOTA | ≥ 0.70 | 多目标跟踪标准指标 |
| IDF1 | ≥ 0.75 | 身份保持能力 |
| ID Switch | ≤ 5 % | 单位小时内 ID 切换次数 |
| 计数准确率 | ≥ 95 % | 人工核对进出总数 |
| 误检率 | ≤ 3 % | 非行人被检测为行人的比例 |
| 漏检率 | ≤ 5 % | 行人未被检出的比例 |

### 5.3 可靠性与稳定性

| 指标 | 要求 |
| :--- | :--- |
| 长时间运行 | 连续运行 ≥ 8 小时无崩溃 |
| 内存泄漏 | 内存增长 ≤ 5 % / 小时 |
| 异常恢复 | 视频源断开自动重连 ≥ 3 次 |
| 资源释放 | 退出时正确释放摄像头、GPU 显存、文件句柄 |

## 6. 接口需求

### 6.1 用户接口（CLI）

| 命令示例 | 说明 |
| :--- | :--- |
| `python main.py --source videos/demo.mp4` | 处理本地视频 |
| `python main.py --source 0` | 打开摄像头 0 |
| `python main.py --config config.yaml` | 使用配置文件运行 |
| `python main.py --source xxx --show --save` | 显示预览并保存结果 |
| `python main.py --device cpu` | 强制使用 CPU |

### 6.2 配置文件接口（config.yaml）

| 配置节 | 字段 | 类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| model | weights | str | `models/yolo11n.pt` | YOLO 权重路径 |
| model | conf | float | 0.25 | 置信度阈值 |
| model | iou | float | 0.45 | NMS IoU 阈值 |
| model | imgsz | int | 640 | 推理输入尺寸 |
| model | device | str | `auto` | `auto/cpu/0/cuda:0` |
| track | tracker | str | `bytetrack.yaml` | 跟踪器配置 |
| track | max_age | int | 30 | 目标消失帧阈值 |
| track | track_buffer | int | 30 | 轨迹缓存长度 |
| count | mode | str | `line` | `line` 或 `region` |
| count | line | list | `[[0,360],[1280,360]]` | 计数线端点 |
| count | region | list | `[]` | 多边形顶点 |
| output | save_video | bool | true | 是否保存标注视频 |
| output | save_csv | bool | true | 是否保存明细 CSV |

## 9. 业务流程

### 9.1 总体流程

| 阶段 | 步骤 | 说明 |
| :---: | :--- | :--- |
| 1 | 启动系统 | 加载配置文件、初始化日志 |
| 2 | 环境检测 | 判断 GPU 可用性，选择运行设备 |
| 3 | 模型加载 | 加载 YOLO 权重与跟踪器 |
| 4 | 视频源打开 | 根据参数打开视频/摄像头/流 |
| 5 | 帧循环处理 | 逐帧读取，直到结束或用户退出 |
| 6 | 目标检测 | YOLO 推理输出 person 目标 |
| 7 | 多目标跟踪 | 分配/维持 track_id |
| 8 | 计数判定 | 判断是否跨越计数线/进入区域 |
| 9 | 可视化渲染 | 绘制框、ID、轨迹、面板 |
| 10 | 数据输出 | 写入视频/CSV/JSON |
| 11 | 资源释放 | 关闭摄像头、释放显存 |

### 9.2 计数判定流程

| 步骤 | 判定条件 | 处理动作 |
| :---: | :--- | :--- |
| 1 | 目标中心点位于计数线上方（前一帧） | 记录 pre_position = "above" |
| 2 | 目标中心点位于计数线下方（当前帧） | 若 pre_position="above" 且 ID 未在 in_set，则 in += 1 |
| 3 | 目标反向穿越 | 若 pre_position="below" 且 ID 未在 out_set，则 out += 1 |
| 4 | 目标未跨越 | 不改变计数 |
| 5 | 目标 ID 消失 | 从状态缓存中移除 |
